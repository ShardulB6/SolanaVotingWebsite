# SolanaVotingWebsite

Created in [T3 Code](https://t3.codes).

The application lives in [`my-better-t-app/`](./my-better-t-app/). It uses TanStack Start, Drizzle, Cloudflare D1, and Vite+. Solana integration will be added separately.

```bash
cd my-better-t-app
pnpm install
pnpm run dev
```

See the [application README](./my-better-t-app/README.md) for database setup, checks, and deployment instructions.
