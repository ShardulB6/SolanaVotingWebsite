# SolanaVotingWebsite

Created in [T3 Code](https://t3.codes).

The application lives in [`my-better-t-app/`](./my-better-t-app/). It uses TanStack Start, Vite+, and Solana wallet sign-in with server-side signature verification.

```bash
cd my-better-t-app
pnpm install
# Create apps/web/.env with AUTH_SESSION_SECRET (see the application README).
pnpm run dev:web
```

See the [application README](./my-better-t-app/README.md) for local development and checks.
