# SolanaVotingWebsite

Created in [T3 Code](https://t3.codes).

The application lives in [`my-better-t-app/`](./my-better-t-app/). It uses TanStack Start and Vite+, with Cloudflare hosting configured through Alchemy. Solana integration will be added separately.

```bash
cd my-better-t-app
pnpm install
pnpm run dev:web
```

See the [application README](./my-better-t-app/README.md) for local development, checks, and deployment instructions.
